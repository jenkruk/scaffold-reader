# Scaffold Reader

A small React app that renders a grade-6 passage with the reading scaffolds each selected student should see.

## Run locally

Vite 8 requires Node 20.19+ or 22.12+ (this project was developed on Node 22).

```sh
npm install
npm run dev        # http://localhost:5173
```

## Other commands

```sh
npm run test:run   # run tests once (npm test runs in watch mode)
npm run typecheck
npm run build
```

## Tech

React, TypeScript, Vite, Tailwind CSS, Vitest / React Testing Library.

See `NOTES.md` for implementation decisions and tradeoffs.
